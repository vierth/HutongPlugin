# Hutong Plugin
Plugin for unreal engine to create geometry and annotate objects made for Building Qianlong's World

This is designed to rapidly prototype the layout of Beijing based on the 1750 map of Beijing (the 乾隆京城全圖).

This is a C++ plugin written with Claude Code (primarily Opus and Fable 5). If you find bugs or run into other issues, please open an issue.

## Installation

Create a "Plugins" folder inside your Unreal Engine project (if one does not exist)

Add the HutongLayout and PlaceLabels folders into the Plugins Folder.

The structure should look like this: 

```
MyProject/
├── ...
├── Plugins/
│   ├── HutongLayout/
│   └── PlaceLabels/
└── ...
```

Start Unreal Engine to compile
